# Text Transformer (Custom Additions)

Maintained source for Alfred Team's **Text Transformer** (`com.alfredapp.vitor.texttransformer`) with local Universal Action transformations added:

- **Unwrap** (`unwrap`)
- **Strip Clean** (`stripClean`)

## Key files

- `workflow/text-transformer.alfredui/components/transformations.json` — transformation menu entries
- `workflow/text-transformer.alfredui/transform` — JXA transformation implementations
- `workflow/text-transformer.alfredui/ui.json` and `components/` — Alfred 6 UI definition
- `workflow/info.plist` — workflow triggers and Alfred UI wiring

Runtime user preferences (`prefs.plist`) and Alfred Gallery screenshots (`images/about/`) are intentionally omitted.
